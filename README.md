# Movie Memory

Stage 1 foundation: Next.js App Router, TypeScript, React, TailwindCSS, and npm.

## Prerequisites

- Node.js 26.8.2 (recorded in `.nvmrc`)
- npm 11.19.1

## Local development

```sh
npm ci
npm run dev
```

Open the local URL printed by Next.js. No environment variables are needed for this scaffold.

## Verification

```sh
npm run typecheck
npm run build
npm run start
```

The type check generates Next.js route types before running TypeScript without emitting files. Stop the development server before building or starting the production server.

The scaffold uses the official TailwindCSS Turbopack integration generated by create-next-app 16.4.5. Direct dependency versions are pinned and `package-lock.json` records the resolved installation.

Prisma, authentication, onboarding, OpenAI integration, caching, and application features are deferred to later stages. Their packages are not installed yet.
